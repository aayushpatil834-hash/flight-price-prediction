# ✈️ Flight Price Prediction using Machine Learning

## 📌 Project Overview
This project predicts airline ticket prices based on various flight details such as airline, source, destination, journey date, departure time, arrival time, duration, and number of stops.

The goal of this project is to help travelers estimate flight prices and understand the factors that influence airfare costs using Machine Learning techniques.

---

## 🚀 Features

✅ Data Cleaning & Preprocessing  
✅ Feature Engineering  
✅ Exploratory Data Analysis (EDA)  
✅ Automated Data Profiling  
✅ Correlation Analysis & Visualization  
✅ Multiple Machine Learning Models Comparison  
✅ Flight Price Prediction System  
✅ Model Serialization using Pickle

---

## 📊 Models Evaluated

- Random Forest Regressor
- Extra Trees Regressor
- XGBoost Regressor
- LightGBM Regressor
- CatBoost Regressor ⭐ (Selected Final Model)

After comparing multiple algorithms, **CatBoost Regressor** was chosen as the final model due to its superior prediction performance.
